# 原型静态素材

`prototype.jpg` 是用户在本次任务提供的 `f00f39efa301efa4551f45d7c9937c30.jpg` 的原样副本，尺寸 1639 × 960。程序通过 Qt 资源 `:/hmi/prototype.jpg` 使用其中的专辑封面与停车场区域；文字、按钮、图标及地图均由 Qt 绘制。

`vehicle-clean.png` 由内置 ImageGen 参考原型中的银白色 SUV 生成，使用与卡片一致的深蓝背景，保留完整车身和轮胎。程序通过 `:/hmi/vehicle.png` 加载并保持比例缩放，不再从原型截图手工裁剪车辆轮廓。

这些照片区域均为静态 UI 素材，不是实时视频或联网地图。字体使用运行系统提供的字体，不将 Windows 字体文件打包进仓库。
