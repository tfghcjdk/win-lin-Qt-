# 原型静态素材

`prototype.jpg` 是用户在本次任务提供的 `f00f39efa301efa4551f45d7c9937c30.jpg` 的原样副本，尺寸 1639 × 960。程序通过 Qt 资源 `:/hmi/prototype.jpg` 使用其中的车辆、专辑封面与停车场区域；文字、按钮、图标及地图均由 Qt 绘制。

照片区域仅用于原型 UI 演示，不是实时视频或联网地图。代码对车辆轮廓进行绘制裁剪，避免复用图中静态胎压数值。后续可用独立高分辨率素材替换，尤其全屏摄像头应接入真实视频源。

素材来源为用户提供，未另行下载网络图片或添加未经确认的外部素材。字体使用运行系统提供的字体，不将 Windows 字体文件打包进仓库。
