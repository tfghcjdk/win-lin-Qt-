# F08 倒车影像

点击首页入口后自动启动 Linux `/dev/video9` V4L2 摄像头，退出覆盖层时自动停止。优先请求 1280 × 720 / 30 FPS，实时画面按后视镜语义水平镜像，通过 `Qt::SmoothTransformation` 按比例缩放，支持 MJPEG/YUYV，并叠加带深色描边的绿、黄、红三段平滑曲线辅助线。近距离输入在画面顶部触发后方障碍物警告；当前设置页可注入 55 cm 状态用于验证，真实雷达尚未接入。辅助线尺寸和警告阈值尚未按具体车型标定。

当前状态：已在 `src/ui/main_window.*`、`hmi_cards.*` 和 `paint_helpers.*` 实现对应 UI / 演示交互；真实设备与服务仍待接入。
