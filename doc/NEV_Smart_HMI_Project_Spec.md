# NEV-SmartHMI 项目启动说明

版本：`0.1.0-skeleton`。初始化日期：2026-09-08。

## 项目目标

为 X6818 开发板规划新能源汽车智能仪表与车载终端，覆盖顶部状态、页面导航、驾驶仪表、续航与胎压、能量流、空调、导航提示、倒车影像、媒体、行车与保养 10 个模块。以 Windows 模拟开发配合 ARM 板端验证，兼容下限为 Qt 5.4.1 / C++11，显示区域为 1024 × 600。

本说明从根目录 `.md` 整理而来。示例中车速、电量、胎压、日期及导航内容都属于原型数据，不代表已连接设备或真实车辆状态。当前输入资料未包含实际原型图片。

## 后续实施顺序

1. 核实板端 ABI、Qt 安装、交叉编译器和 sysroot，补齐工具链及部署参数。
2. 开始功能开发后建立最小 `QApplication` / `MainWindow`，接入应用构建目标，分别在 Windows 和 ARM 验证基础窗口。
3. 定义车载数据、控制命令、有效性与时间戳，建立模拟数据通路。
4. 根据 PRD 逐模块开发 1024 × 600 界面与交互，保持 UI 与硬件采集分层。
5. 逐项接入真实 CAN / UART、摄像头、音频和系统服务，验证断连、异常与退出流程。
6. 在真实开发板验证显示、触控、资源占用、数据时效及部署方式，完成验收记录。

以上步骤均为计划，不表示本阶段已完成对应功能。各步骤所需的源代码待用户后续指示开发。
