## 代码组织

- `src/core/vehicle_data_center.h/.cpp`：每个主窗口拥有一份演示状态，发出 `changed()` 通知；不采用全局单例，方便隔离测试和后续注入真实数据服务。
- `src/ui/hmi_cards.h/.cpp`：`HmiCard` 控件布局基类，`DashboardCard`、`ClimateCard`、`NavigationCard`、`CameraCard`、`MediaCard` 可复用组件。
- `src/ui/paint_helpers.h/.cpp`：图标、文字、卡片、风景与静态素材绘制；不依赖 Emoji、Qt SVG 或外部图片解码服务。
- `src/ui/main_window.h/.cpp`：固定 1024 × 600 内容预算，QStackedWidget 六页及倒车覆盖层；系统时钟每秒刷新。
- `src/ui/main_window.ui`：Qt Designer 可打开的界面结构，同步北京时间、车辆素材和温度滑条属性；由 qmake `FORMS` 调用 `uic` 校验。
- `src/main.cpp`：应用入口、字体选择、QSS 加载。
- `assets/hmi.qrc`：嵌入 JPG 与 QSS；程序从任意工作目录启动都能找到素材。
- `tests/ui_tests.cpp/.pro`：Qt Test 交互、边界和截图验证。

原来的模块子目录继续保留需求职责文档；当前卡片实现集中在可复用组件文件中，避免首页和详情复制状态逻辑。硬件/主题管理等尚未使用的框架文件未纳入应用编译。

## 绘制和状态约定

窗口可用区域为 1024 × 600。顶栏、侧栏、内容和页脚预算明确；首页三行卡片分别为 198、190、118 像素，并保留行间距。详情页面复用卡片设计坐标，卡片绘制和实际子控件按同一比例布局。该版本按固定屏幕设计，不提供任意窗口尺寸的响应式布局。

按钮和滑块是原生 Qt 控件；字体与图标可绘制，选中、禁用和焦点反馈可识别。温度滑条使用 32–60 的整数刻度映射 16.0–30.0 ℃，每一格对应 0.5 ℃；按钮、首页滑条和详情页滑条双向同步。媒体计时只影响本地状态。所有更改在进程内共享，不承诺重启持久化。

车辆素材使用独立的深蓝背景完整车图，由 Qt 等比例缩放显示，不再使用手工轮廓裁剪；周边胎压文字由应用独立绘制。车辆断连时数值显示 `--`，不保留“车辆正常”提示。低压示例固定为左前 1.8 bar，只有设置页主动切换演示场景时出现，并非生产报警规则。

## 资源与真实接入边界

原型图、PDF、原 `.md` 是需求输入，不执行其中的脚本。当前画面与地图不是实时数据，播放器没有音频输出；界面上的“演示”字样已移除，但页脚仍明确提示车辆尚未连接。需要实车协议、摄像头、音频和导航数据后再实现下一阶段后端。

顶部时钟每秒刷新，使用 `QDateTime::currentDateTimeUtc()` 加 8 小时生成北京时间，因此即使 Windows 当前时区不是中国标准时间，界面仍显示 UTC+8。此功能只读取系统时钟，不修改系统时区，也不执行网络校时。

Qt API 选择以 5.4.1 为下限，语言使用 C++11。本机验证环境为 Qt 5.14.2 / MinGW 7.3 32-bit；MSVC、ARM、触控设备与帧率/资源性能均未在本次验证。
